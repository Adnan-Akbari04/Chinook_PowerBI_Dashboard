# Chinook Music Store Analytics Dashboard

## 📊 Overview
A comprehensive Power BI dashboard analyzing the Chinook digital music store dataset. This interactive dashboard provides insights into sales performance, customer behavior, artist popularity, and business operations.

## 🎯 Dataset Information
**Chinook Database** - A fictional digital media store database representing a music platform similar to iTunes or Spotify. Contains 11 interconnected tables with real-world business data including:
- Artists, albums, and tracks information
- Customer demographics and purchase history
- Sales transactions and invoices
- Employee and operational data
- Music genres and media formats

**Data Characteristics:**
- Clean, structured relational data
- Realistic business scenarios
- Time-series sales data
- Geographical customer distribution
- Comprehensive music catalog

## 🏗️ Project Structure

## 🔧 Technical Details
- **Tool:** Microsoft Power BI Desktop
- **Data Model:** Star schema with optimized relationships
- **Pages:** 5 interactive report pages
- **Measures:** Custom DAX calculations for business metrics
- **Visuals:** Interactive charts, maps, and KPIs
- **Design:** Professional color scheme with responsive layout

  
## 📦 Required Files Download

Before opening the dashboard, you must download the necessary files:

1. **Go to the repository's main page**
2. **Download the `Chinook_PowerBI_Dashboard.rar` file**
3. **Extract it into your project folder**

**The extracted folder should contain:**
- `Chinook_Music_Analytics.pbix` (main Power BI dashboard file)
- `Chinook_SqlServer.sql` (SQL script to recreate the database)


## 🚀 Quick Start Guide

### **Option 1: Use PBIX File (Recommended)**
1. Extract the RAR file
2. Open `Chinook_Music_Analytics.pbix` with Power BI Desktop
3. Start exploring immediately - all data is embedded

### **Option 2: Recreate Database from SQL**
1. Extract the RAR file
2. Run `Chinook_SqlServer.sql` in SQL Server Management Studio
3. Connect Power BI to your local database instance
4. Import and transform data as needed


## ❓ Troubleshooting

For questions or issues with this Power BI project:
1. Ensure you have **Power BI Desktop** installed (latest version recommended)
2. The `.pbix` file contains all embedded data - no external connections needed
3. If using the SQL script, ensure you have **SQL Server** or compatible database system

Check that you've downloaded all required files and have the necessary software installed before reporting issues.
